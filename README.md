# 🗺️ M.A.P.A. COMUNITARIO
### Monitoreo y Alerta de Proyectos Autónomos para el Desarrollo
**Un proyecto de código abierto para [ccomusoc.com.ar](https://ccomusoc.com.ar)**

---

La plataforma tecnológica y participativa diseñada para visibilizar, geolocalizar y medir el impacto de las intervenciones sociales en los territorios en tiempo real.

## 🚀 Características Clave
*   **Mapeo Participativo:** Registro de iniciativas territoriales (Salud, Educación, Ambiente, Deporte Social) con coordenadas en tiempo real.
*   **Soporte Offline Completo:** Los datos se guardan de forma local en el navegador si no hay señal en el territorio y se sincronizan automáticamente al recuperar la conexión.
*   **Inteligencia Territorial:** Integrado con **Google AI Studio (Gemini)** para procesar testimonios de forma fluida y generar reportes.
*   **Gestión Automatizada:** Sincronización de fondo con Google Sheets para el seguimiento administrativo automático.

## 🛠️ Tecnologías Abiertas Utilizadas
*   **WordPress:** Servidor principal y base del plugin nativo para la web.
*   **Leaflet.js & OpenStreetMap:** Cartografía libre, ligera y soberana (sin APIs de pago).
*   **Google AI Studio:** Procesamiento de lenguaje natural para análisis de impacto social.
*   **GitHub:** Alojamiento y despliegue continuo de código.
